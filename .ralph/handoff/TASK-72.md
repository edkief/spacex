Don't try to vi.mock three.js for this — too many modules depend on it.
- **three 0.186 typings have no `disposeCount`** on BufferGeometry/Material (first draft of the dispose test used it); assert `group.children.length === 0` after dispose instead.
- **Chase pose test math:** `|look − position|` is NOT `CHASE_LOOK_AHEAD + CHASE_BEHIND` (the 4 u height offset makes it `sqrt(4² + 34²)`). The pose tests compare against exact `quatRotateVector` results instead — keep them that way.
- **`handoff('chase')` no-op trap:** `CameraRig.handoff` returns false when `to === this.mode`. That's why `setSelfShip` only sets `mode='chase'` when `rigActive` was false (boot); re-entry relies on `reEnterShip`'s handoff while mode is still 'onfoot'. main.tsx calls `setSelfShip` before `reEnterShip` — keep that order.
