# Galaxy Determinism Fixtures

These JSON files serve as regression guards for the galaxy generator. 

They ensure that for a given seed (e.g., `dev-seed`), the generated star chart, systems, and surface chunks are byte-stable across different runs and platforms.

## Updating Fixtures

Fixtures must only be regenerated by an explicit, deliberate command after an approved change to the generator logic.

To update fixtures:
```bash
npm run snapshot:update
```

Any PR that modifies these files must include a justification for the change in the commit message.
